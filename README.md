# Shape Calculator Flask Application
This is a Flask-based web application that allows users to calculate the area, perimeter, and volume of various geometric shapes like rectangles, cylinders, cuboids, and circles.

## Features
- **Rectangle**: Calculate the area and perimeter.
- **Cylinder**: Calculate the surface area and volume.
- **Cuboid**: Calculate the surface area and volume.
- **Circle**: Calculate the area and circumference.
